### SSL 인증서가 걸리는 이유

Render는 연결된 도메인에 Let's Encrypt·Google Trust Services 인증서를 **자동 발급·갱신**하는
방식만 제공하고, 사용자가 인증서 파일을 올리는 기능이 없다(<https://render.com/docs/tls>).
따라서 회신 메일에서 **자동 발급 인증서로 갈음할 수 있는지**를 먼저 묻는다.

- 갈음 가능 → 지금 구조 그대로 진행.
- 중앙대 인증서가 반드시 필요 → 인증서를 직접 설치할 수 있는 환경으로 옮겨야 한다.
  후보는 연구실 서버(고정 IP + 보안정책 등록) 또는 nginx를 올린 소형 VPS. 회신을 받고 결정한다.

## 2. 누가 누구에게 보내는가

사전 문의는 **본인 메일**로 보냈고 회신도 본인에게 왔다. 그래서 교수님 명의가 꼭 필요한
**사용 중지 요청만** 교수님이 보내시고, 나머지 확인 질문과 양식 요청은 본인이 같은 메일
흐름에 답장으로 처리한다.

| 순서 | 보내는 사람 → 받는 사람 | 내용 |
|---|---|---|
| ① | 본인 → 조용문 선생님 (받은 회신에 **답장**) | 재신청 이름·CNAME 확인, SSL 인증서 문의, **점검표 양식·작성 가이드 요청** (3장) |
| ② | 본인 → 교수님 | 진행 순서 + 단계별 화면 안내: 사용 중지 메일, 점검표 양식 다운로드, 신규 신청 방법 (4장) |
| ③ | 교수님 → 조용문 선생님 (**새 메일**, 본인 참조) | 기존 도메인 사용 중지 요청 |
| ④ | 본인 → 교수님 | 작성한 점검표 2종 + 신청서 기재값 |
| ⑤ | 교수님 | 종합정보시스템에서 신규 도메인 신청 → 승인요청 |

①과 ②는 동시에 보내도 된다. 사용 중지는 SSL 답과 무관하게 해도 손해가 없다
(지금 psynr은 종료된 Wix를 가리켜 404다).

> 본인 계정으로 종합정보시스템 도메인 신청 페이지가 열려서 양식을 받을 수 있다면,
> ①의 3번(양식 요청)은 빼고 보낸다.
